# 🎲 Dice Roller

A simple and interactive web application that lets you roll one or multiple dice and displays the results with visual dice images.

## Features

- 🎯 **Roll Multiple Dice** - Choose between 1-10 dice to roll at once
- 🖼️ **Visual Feedback** - See dice face images for each roll result
- 📊 **Result Display** - View all rolled values in an easy-to-read format
- 🎨 **Clean UI** - Simple and intuitive user interface

## How to Use

1. Enter the number of dice you want to roll (1-10)
2. Click the **Roll** button
3. View the results with corresponding dice images

## Technologies Used

- **HTML5** - Structure and layout
- **CSS3** - Styling and design
- **JavaScript** - Game logic and interactivity

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. Start rolling! 🎲
